# Bulkhead

Write an access policy for an AI agent's tools. Bulkhead attacks it and shows the shortest way around it.

## Status

Under construction. Nothing here is usable yet.

## What it will do

- A pretend world with real tool behavior.
- Tracking of where each piece of data came from.
- An attack search that finds the shortest bypass of a policy.
- A check against a real MCP filesystem server.

## What it will not do

- It is not a proxy or a gateway.
- It does not test real language models.
- It cannot catch leaks that are paraphrased or reasoned.

## How it is built

Specs and design by me. Code typed by an AI coding model (Gemini Flash), checked by tests and by the attacker.
